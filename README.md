# ECG Monitoring Using ESP32 and AD8232

An educational embedded systems and IoT project focused on ECG signal acquisition, waveform visualization, and remote monitoring.

## Overview

This project explores the use of an ESP32 microcontroller and an AD8232 ECG sensor to capture electrical signals from the heart and visualize the resulting ECG waveform.

The project also demonstrates sending ECG readings to an IoT cloud platform, providing an introduction to connected health-monitoring systems.

## Objectives

- Explore ECG signal acquisition using the AD8232 sensor.
- Interface the sensor with an ESP32 microcontroller.
- Visualize the acquired ECG waveform.
- Explore IoT-based transmission of ECG readings for remote monitoring.

## Hardware Components

- ESP32 development board
- AD8232 ECG sensor module
- Electrodes
- Breadboard
- Connecting wires

## Technologies

- Embedded Systems
- ESP32
- ECG Signal Acquisition
- Internet of Things (IoT)
- Cloud-Based Monitoring

## Working Principle

1. The AD8232 sensor acquires electrical signals from the body through the attached electrodes.
2. The sensor outputs an analog signal to the ESP32.
3. The acquired signal is used to visualize the ECG waveform.
4. ECG readings are transmitted to an IoT cloud platform for remote monitoring.

## Learning Outcomes

- Hands-on experience with microcontroller and sensor interfacing.

- Exposure to IoT-based data transmission.

## Disclaimer

This is an educational prototype intended for learning and experimentation. It is not a medical device and must not be used for diagnosis or treatment.
